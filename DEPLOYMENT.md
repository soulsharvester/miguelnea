# GitHub Pages

This is a static demo app. It uses browser modules and local storage; it does not require a build step or a server-side backend.

The `Deploy to GitHub Pages` workflow publishes the repository on pushes to `main` and can also be run manually from the Actions tab. In the repository settings, set **Pages** > **Build and deployment** > **Source** to **GitHub Actions**.

For this repository, the site URL is <https://soulsharvester.github.io/miguelnea/>. The first deployment starts after the workflow runs successfully. All local script and stylesheet references are relative so the site works under the repository path.
